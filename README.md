# ✨ SoulSpace — Sunday School Library Web App

A mobile-friendly, beautiful React + Supabase web application for managing a Sunday school library (~500 books). Designed for non-technical volunteers with a clean, vibrant, and approachable UI.

## Features

- **Catalog & Search**: Instant filtering by title, author, category, or ISBN.
- **Borrowing Flow**: Captures Borrower Name, Grade level, and optional Notes.
- **Dedicated Checkout History UI**: Dedicated history view with status pills, grade breakdown, and CSV export.
- **Restricted Returns**: Only logged-in Admins can mark books as returned.
- **Automatic History Cleanup**: Returned items older than 2 months are automatically pruned.
- **Admin Management**: Full CRUD operations for books.

## Getting Started

```bash
npm install
npm run dev
```

Runs on [http://localhost:5173](http://localhost:5173).
